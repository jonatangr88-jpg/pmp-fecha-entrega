# PMP Fecha de Entrega

Plugin propio para WooCommerce desarrollado para Pilar Merello.

## Objetivo

Permitir al cliente seleccionar una fecha de entrega mediante un calendario Flatpickr únicamente en los productos que lo requieran.

## Funciones V1

- Selector de fecha
- Flatpickr
- Fecha mínima
- Fecha máxima
- Intervalos bloqueados
- Guardado en carrito
- Guardado en pedido
- Emails
- Configuración en WooCommerce
